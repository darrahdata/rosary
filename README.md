# The Holy Rosary

A simple, mobile-friendly web app for praying the Rosary.

This project is designed as a contemplative prayer companion with a Marian blue and ivory visual identity, clear mystery selection, rosary type selection, and a bead-by-bead prayer flow.

Live site: https://darrahdata.github.io/rosary/

## Features

- Guided Rosary prayer flow
- Rosary type selection
  - Dominican Rosary
  - Franciscan Crown
  - Divine Mercy Chaplet
- Mystery selection
  - Joyful
  - Luminous
  - Sorrowful
  - Glorious
  - All Mysteries
- Visual rosary bead progress graphic
- Bead count and current prayer display
- Previous and next controls
- Mobile-friendly layout
- Self-contained `index.html` file
- Hosted with GitHub Pages

## Purpose

The goal of this app is to provide a quiet, accessible way to pray the Rosary from a phone, tablet, or desktop browser.

The design is intentionally simple: soft ivory background, Marian blue accents, pearl-like beads, and large touch targets for ease of use.
